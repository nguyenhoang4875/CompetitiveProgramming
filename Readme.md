# CompetitiveProgramming

A personal **competitive programming** repository containing problem solutions, practice notes, algorithm references, and topic-based exercises written primarily in **C++**.

## Overview

This repository appears to be a collection of:

- Solutions for online judges and contests
- Notes and templates for competitive programming
- Practice by topic such as:
  - data structures
  - dynamic programming
  - graph theory
  - number theory
  - pointers / C++ basics

It serves as both a **practice archive** and a **reference library** for problem solving.

## Repository Structure

Some of the main folders and files include:
- `aglo_libs/` — algorithm/helper library code
- `cp_book/` — material inspired by competitive programming books

## Notes and Style

This repository includes personal notes such as:

- avoiding unnecessary floating-point usage when possible
- formatting decimal output in C++
- using `hypot(...)` for Euclidean distance
- difference array / prefix sum tricks for interval updates
- modular indexing helpers
- a reusable problem-analysis template

Example topics from `CP_Note.md` suggest a workflow focused on:

1. summarizing the problem
2. identifying key observations
3. designing an approach
4. checking edge cases
